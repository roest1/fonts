The default for the shell, nvim's chrome and Claude Code panes in WezTerm.

- Its advance is 0.62em. Science Gothic Mono is built to that same advance so the two can share one grid.
- It has no glyph for U+23FA or U+23BF, which Claude Code draws on every tool call. Those two fall back to another font and come back wider than the cell.
