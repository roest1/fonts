The one family tested that has all nine glyphs Claude Code draws, including the two it draws on every tool call (U+23FA and U+23BF), and also keeps the Nerd Font icons at exact cell width.

- Its advance is 0.50em against 0xProto's 0.62em. That is fine for a lane of its own. It is the wrong base font while the editor lane is a 0.60em font, because the editor lane draws inside the base font's cell.
